# Third-party notices

This repository currently bundles no third-party code.

Rule: nothing lands as vendored/bundled third-party material without (1) a
licence compatible with Apache-2.0 *for this act of redistribution*, (2) an
entry here naming upstream, version, licence, and local path, and (3) a line in
the root `NOTICE`. Dependency-level use (declared in `pyproject.toml`) also
needs the compatibility check, and anything copyleft is refused outright if it
would cross the boundary described in README ("Why independent is
load-bearing").
